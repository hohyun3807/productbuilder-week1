## 게임 소개
클래식 테트리스 게임입니다. 떨어지는 블록을 배열하여 가로줄을 완성하면 사라집니다.

## 조작법
- **← →** : 좌우 이동
- **↓** : 빠른 하강
- **Z** : 시계 반대 회전
- **X** : 시계 방향 회전
- **Space** : 바닥에 바로 떨어짐

## 게임 기능
- ✅ 7가지 테트로미노 (I, O, T, S, Z, J, L)
- ✅ 점수, 라인, 레벨 시스템
- ✅ 다음 블록 미리보기
- ✅ 난이도 상승 (라인 10개마다 레벨 업)
- ✅ 게임 시작/일시정지 기능
- ✅ 네온 테마의 멋진 디자인

## 파일 구조
- `index.html` - 게임 화면 및 UI
- `style.css` - 게임 스타일
- `tetris.js` - 게임 로직
